# 股票领域 Skill

## 目标
系统性地发现、监控和复盘股票投资领域的视频内容创作者，
追踪其分析质量，积累可信信息来源。

## 工作流

### 1. 发现 (discover)
- 搜索热门股票相关视频
- 使用 search_authors 工具获取作者列表
- 筛选出有潜力的创作者

### 2. 监控 (monitor)
- 定期拉取已订阅作者的最新视频
- 转录并分析内容
- 自动记录分析摘要

### 3. 复盘 (review)
- 评估作者近期分析质量
- 更新评分和黑名单
- 生成复盘报告

## 评分标准
- 高价值 (0.7+): 分析准确、逻辑清晰
- 中等 (0.3-0.7): 内容一般，部分有价值
- 低价值 (<0.3): 质量差或误导性内容
- 黑名单: 明显虚假信息或恶意误导

## 平台支持
- bilibili: 中文股票分析视频
- youtube: 中英文财经内容
- douyin: 短视频财经分析
