# 每日公开日报与Git提交

仅当用户已授权每天提交推送时执行。发布内容是作者观点的原创摘要、历史观点对照、市场事实、判断验证、综合情景操作参考及来源链接。原视频和全文转录留在本地，不公开账号资料、关注关系、持仓、资金或登录信息。

## 从归档版本发布

1. 先由`save_daily_research`保存真实日报。返回report_path后，同目录同revision的JSON文件为本次归档输入。不要把模板、虚构示例或未完成分析当成真实日报。
2. 对公开report正文做内容审阅：每位研究作者都有观点或缺口状态；引用包括原视频和时间戳；历史不足明确；操作参考有依据、触发/失效条件和期限。本地路径、邮箱、个人关注或转录全文不进入公开正文。原始source artifact ID只保留本地，公开版本移除内部归档段。
3. 用项目工具导出并推送：

   `.venv/Scripts/python.exe scripts/publish_daily_report.py --record <已保存revision.json的绝对路径> --push`

   脚本在`html/skills/daily/YYYY-MM-DD/<revision>.md`保留版本，更新`html/skills/daily/index.json`和`github.html`的日报链接。网页只展示真实已发布报告；第一天索引为空。
4. 脚本只允许当前分支main、配置的GitHub origin；只提交本次日报、日报索引和github.html。遇到已有用户暂存文件、其他网页改动或远端拒绝，停止提交/推送并报告，不清空用户暂存区，不force-push，不自动改写历史。GitCode及旧dev/master不推送。
5. 结果分别报告本地导出、commit、push。推送失败时报告本地commit和错误状态，不能写“已上传”。下一次可在核实当前main和远端状态后正常重试，不为凑每日提交制造重复报告。

## 休市与重复运行

对同一D日同一revision的报告复用既有公开文件；不增加重复验证样本。没有新材料、报告与索引没有变化时不创建空提交。如果休市期间有新的可核实补充，单独说明补充日期及其预测窗口，不能伪装新交易日收盘。

## 运行边界

helper仅做文件导出和Git发布，不抓取行情、不转录视频、不生成建议。市场和观点研究由Skill完成。用户后续撤销公开发布时立即停止--push，仍可本地归档。数据源全失败时只本地保存失败说明和告知用户，不发布空白“完成日报”。
